# セーブコード（じゅもん）と つづきコードの しくみ

**日本語** | [繁體中文](save-code.zh-TW.md) | [English](save-code.en.md) · [README にもどる](../README.md)

このゲームには 2 種類のコードがあります。

| | じゅもん（セーブコード） | つづきコード |
|---|---|---|
| 中身 | 全体の進みぐあい（コイン、おみせ、じっせき、ステージの記録など） | 遊んでいる途中の 1 ゲーム |
| 長さ | いまは 104 文字（4 文字 × 26 グループ） | 中身によって変わる（4 の倍数、じゅもんの長さとは重ならない） |
| ソース | `src/save.js` | `src/runcode.js`（チェックは `src/main.js` の `runProblem`） |

> **大事なこと：** ゲームは ぜんぶ ブラウザの中だけで動きます（サーバーはありません）。ソースを読めば、だれでも コードを 読んだり 作ったり できます。チェックサムは **打ちまちがいを見つけるため** だけのもので、ずるを ふせぐ しくみでは ありません。

このページの表は `node tools/gen-save-docs.mjs` が ソースから そのまま 作っています（`npm test` で ずれていないか チェックします）。

## 共通のルール

- **文字**：31 文字 `23456789ABCDEFGHJKMNPQRSTUVWXYZ`。まぎらわしい `0 O 1 I L` は 使いません。
- **入力の ゆるさ**：入力は NFKC で 半角にして 大文字にし、空白・ハイフン・長音・中黒・句読点などを 消してから 読みます（`normalize`）。
- **グループ**：表示するときは 4 文字ごとに `-` で 区切ります。

## じゅもん（セーブコード）の 作りかた

1. 下の表の フィールドを 上から じゅんに つなげて 1 つの 大きな 整数に します（最初のフィールドが いちばん上の ビット）。
2. 版ごとに きまった マスクと XOR します。
3. うしろに CRC-12（多項式 `0x80F`、初期値 0）を つけます。
4. 版ごとの 定数を かけて `31^文字数` で わった あまりを とります（少しの ちがいで コード全体が かわるように するため）。
5. 31 進数で ちょうど その文字数に して、4 文字ずつ 区切ります。

読むときは 逆の じゅんで もどし、CRC と 値の はんいを たしかめます（`decodeFmt`）。

### 版の 見分けかた

版は **文字数** で 見分けます。3 ビットの `ver` フィールドには 版の番号の 下 3 ビットが 入るので、v8 は 0 です。v1 だけは 定数を かけず、CRC-10（`0x233`）です。

### じゅもんを 入れたとき（復元）

- 全体の進みぐあいは **まるごと 入れかわります**。いまの セーブと まざることは ありません（`fixProfile` で 足りない 項目を うめるだけ）。
- 古い版に ない 項目（新しい おみせ、新しい じっせき、新しい ステージなど）は 0 / なし に なります。
- 言語は、プレイヤーが もう えらんでいれば その言語のまま です。
- 入れたあと、いまの版の じゅもんが 表示されます。
- 遊んでいる途中の ゲーム（つづきコード）は さわりません。復元で まだ ひらいていない ステージや キャラに なった場合も 消さずに のこし、次に ひらいたとき 理由を 表示します（下を 見てね）。

## つづきコード

### 作りかた

1. 先頭に 1 ビット（番兵）を おき、下の 固定部分、そのあとの 可変部分を つなげます。
2. 番兵 以外を きまった マスクと XOR します。
3. CRC-16（多項式 `0x1021`、初期値 `0xFFFF`、番兵も ふくむ）を うしろに つけます。
4. 長さ L は、4 の倍数で、`31^L` に おさまる いちばん小さい 数です。ただし じゅもんの 長さ（SAVE_LENS）は とばします。
5. `31^L` で 定数を かけ、31 進数に して 4 文字ずつ 区切ります。

`ver` は 2 ビットなので、いまの 3 が 入れられる 最後の 番号です。次に 形を かえるときは べつの しるしが 必要です。

### つづきコードの チェック（`runProblem`）

上から じゅんに しらべ、最初に ひっかかった 理由を かえします。

| じゅん | しらべること | 理由 |
|---|---|---|
| 1 | 読めない（文字・長さ・CRC・はんいの まちがい） | `check` |
| 2 | その ゲームの ID が もう おわった ゲームの リストに ある | `used` |
| 3 | ステージ・キャラ・むずかしさが ない、レベルが 1 より 小さい | `check` |
| 4 | その ステージか キャラが いまの セーブで ひらいていない | `locked` |
| 5 | `road` 以外の むげんモードで、クリアしていない／むげんモードが ひらいていない | `locked` |
| 6 | むげんモードでは ないのに 5:00 を こえている | `check` |
| 7 | ステージ専用の ぶきを、その ステージ・`road`・クリアずみの ステージ・はじめから もっている ぶき 以外で もっている | `locked` |
| 8 | （kyonkyon で はじめた ゲーム 以外）ぶきが スロットより 多い、または アイテムが 5 こより 多い。スロットは 6、むげんモードの 5:00 から 5:00・6:30・8:00・9:30 に 1 つずつ ふえて 最大 10 | `check` |
| 9 | パワーアップの かずが 上限より 多い（`b_spd`・`b_mag`・`b_regen` 20、`b_cd`・`b_area` 25、ほかは 上限なし） | `check` |
| 10 | たおした数が 40 × 秒 + 100 より 多い、コインが 4 × 秒 + 300 より 多い、ボスが 1 + 秒 ÷ 60 より 多い | `check` |
| 11 | もう もらった コインが、その ゲームで もらえる コイン（いまの セーブの コインの おみせレベルで 計算）より 多い | `check` |

- **タイトルで 入力したとき**：理由を メッセージで 出し、そのコードでは はじめません。
- **ブラウザに のこった ゲームを ひらいたとき**：`used`（もう おわった ゲーム）だけは だまって 消します。`check` と `locked` は 消さずに のこし、「つづきから 遊ぶ？」の 画面で 理由と コードを 見せて、「のこしておく」か「すてる」を えらべます。すてても コインは もらえません。
- コインは ゲームが おわったとき（ゲームオーバー、クリア、やめる、最初から）に 1 回だけ もらえます。おわった ゲームの ID は のこるので、同じ つづきコードで 2 回 もらうことは できません。

## ブラウザに 保存する もの（localStorage）

同じ サイト（オリジン）なら パスに 関係なく 共通です（トップの URL と `/dist/` も 同じ データ）。

| キー | 中身 |
|---|---|
| `kyoka-save-v3` | 全体の進みぐあい（JSON、まるめなし） |
| `kyoka-save-v2`, `kyoka-save-v1` | 昔の 保存（じゅもん文字列）。`kyoka-save-v3` が ないときだけ 読みます |
| `kyoka-run` | 遊んでいる途中の ゲーム（つづきコード） |
| `kyoka-runs-done` | おわった ゲームの ID（JSON 配列、さいごの 300 こ） |
| `kyoka-lang` | えらんだ 言語 |
| `kyoka-sel` | さいごに えらんだ キャラ・ステージ・むずかしさ（JSON） |
| `kyoka-spseen` | 必殺技の えんしゅつを 1 回 見た（2 回目から スキップできる） |
